# imgstax Video Creation Utilities

This directory contains OS-specific scripts for compiling stacked images (generated by imgstax) into video files using ffmpeg.

## Overview

After using imgstax to create a sequence of stacked images, these utilities help you compile them into a video file with various quality and codec options.

## Prerequisites

**Required**: ffmpeg must be installed on your system

### Installation

**macOS**:
```bash
brew install ffmpeg
```

**Ubuntu/Debian**:
```bash
sudo apt-get update
sudo apt-get install ffmpeg
```

**CentOS/RHEL**:
```bash
sudo yum install ffmpeg
```

**Windows**:
1. Download from [ffmpeg.org/download.html](https://ffmpeg.org/download.html)
2. Extract to a directory (e.g., `C:\ffmpeg`)
3. Add to PATH environment variable

## Scripts

### 1. create_video.py (Recommended - Cross-Platform)

**Python script that works on all operating systems**

```bash
python create_video.py <input_directory> [options]
```

**Features**:
- Cross-platform (Windows, macOS, Linux)
- Color-coded output
- Automatic codec detection from file extension
- Comprehensive error handling
- Progress information

**Examples**:
```bash
# Basic usage
python create_video.py output_directory

# Custom output and settings
python create_video.py output_dir -o timelapse.mp4 -f 60 -q high

# H.265 codec for better compression
python create_video.py output_dir -c libx265 -q high

# Scale down to 720p
python create_video.py output_dir -s -1:720

# WebM format
python create_video.py output_dir -o video.webm -c libvpx-vp9

# Skip confirmation prompt
python create_video.py output_dir --force
```

**Options**:
- `-o, --output FILE` - Output filename (default: output_<timestamp>.mp4)
- `-f, --fps NUMBER` - Frames per second (default: 30)
- `-c, --codec CODEC` - Video codec (libx264, libx265, libvpx-vp9, prores)
- `-q, --quality LEVEL` - Quality preset (low, medium, high, lossless)
- `-s, --scale WxH` - Scale video resolution
- `--force` - Skip confirmation prompt

### 2. create_video.sh (macOS/Linux)

**Bash script for Unix-like systems**

```bash
./create_video.sh <input_directory> [options]
```

**Features**:
- Native bash implementation
- Color-coded output
- Detailed settings display
- Interactive confirmation

**Examples**:
```bash
# Basic usage
./create_video.sh output_directory

# Custom settings
./create_video.sh output_dir -o video.mp4 -f 60 -c libx265 -q high

# Scale to 1080p
./create_video.sh output_dir -s 1920x1080
```

**Options**:
- `-o, --output FILE` - Output video file
- `-f, --fps NUMBER` - Frames per second
- `-c, --codec CODEC` - Video codec
- `-q, --quality LEVEL` - Quality preset
- `-p, --pattern GLOB` - Image filename pattern
- `-s, --scale WxH` - Scale video resolution
- `-h, --help` - Show help message

### 3. create_video.bat (Windows - Batch)

**Windows batch script**

```cmd
create_video.bat <input_directory> [output_file] [fps] [quality]
```

**Examples**:
```cmd
REM Basic usage
create_video.bat output_directory

REM With custom settings
create_video.bat output_dir timelapse.mp4 60 high

REM Lossless quality
create_video.bat output_dir video.mp4 30 lossless
```

**Arguments**:
1. Input directory (required)
2. Output file (optional, default: output_<timestamp>.mp4)
3. FPS (optional, default: 30)
4. Quality (optional, default: high) - Options: low, medium, high, lossless

### 4. create_video.ps1 (Windows - PowerShell)

**PowerShell script with advanced features**

```powershell
.\create_video.ps1 -InputDirectory <path> [options]
```

**Features**:
- Modern PowerShell implementation
- Parameter validation
- Detailed output
- Error handling

**Examples**:
```powershell
# Basic usage
.\create_video.ps1 -InputDirectory output_directory

# Custom settings
.\create_video.ps1 -InputDirectory output_dir -OutputFile timelapse.mp4 -Fps 60 -Quality high

# H.265 with scaling
.\create_video.ps1 -InputDirectory output_dir -Codec libx265 -Scale "-1:720"

# Skip confirmation
.\create_video.ps1 -InputDirectory output_dir -Force
```

**Parameters**:
- `-InputDirectory` (required) - Directory with stacked images
- `-OutputFile` - Output video filename
- `-Fps` - Frames per second (default: 30)
- `-Codec` - Video codec (libx264, libx265, libvpx-vp9, prores)
- `-Quality` - Quality preset (low, medium, high, lossless)
- `-Scale` - Video resolution scaling
- `-Force` - Skip confirmation prompt

## Codecs

### H.264 (libx264) - Default
- **Best for**: General purpose, wide compatibility
- **Format**: .mp4
- **Pros**: Excellent compatibility, good quality/size ratio
- **Cons**: Larger files than H.265
- **Use when**: You need maximum compatibility

### H.265 (libx265)
- **Best for**: High quality with smaller file sizes
- **Format**: .mp4, .mov
- **Pros**: Better compression than H.264 (~50% smaller)
- **Cons**: Slower encoding, less compatible with older devices
- **Use when**: File size is important and target devices support H.265

### VP9 (libvpx-vp9)
- **Best for**: Web videos, YouTube
- **Format**: .webm
- **Pros**: Open source, good compression, web-friendly
- **Cons**: Slower encoding than H.264
- **Use when**: Creating web content or need open-source codec

### ProRes (prores)
- **Best for**: Professional video editing
- **Format**: .mov
- **Pros**: High quality, editing-friendly, industry standard
- **Cons**: Very large files
- **Use when**: Video will be edited further in professional software

## Quality Presets

| Preset    | File Size | Encoding Speed | Use Case |
|-----------|-----------|----------------|----------|
| **low**   | Smallest  | Fastest        | Quick previews, web thumbnails |
| **medium**| Medium    | Moderate       | General sharing, social media |
| **high**  | Large     | Slow           | High-quality output, archival |
| **lossless** | Largest | Slowest     | Maximum quality, professional work |

## Scaling Options

Scale videos during encoding to reduce file size or fit target resolution:

```bash
# Scale to specific resolution
-s 1920x1080          # Full HD
-s 1280x720           # HD 720p

# Scale height, maintain aspect ratio
-s -1:720             # Height 720px, auto width
-s -1:1080            # Height 1080px, auto width

# Scale width, maintain aspect ratio
-s 1920:-1            # Width 1920px, auto height
```

## Typical Workflows

### 1. Quick Preview
```bash
python create_video.py output_dir -q low -f 60
```
Fast encoding, good for checking if the sequence looks correct.

### 2. Social Media (Instagram, Twitter)
```bash
python create_video.py output_dir -o social.mp4 -f 30 -q medium -s 1080:1920
```
Good quality, manageable file size, vertical format.

### 3. YouTube Upload
```bash
python create_video.py output_dir -o youtube.mp4 -f 60 -c libx264 -q high
```
High quality H.264, 60 fps for smooth playback.

### 4. Archival/Maximum Quality
```bash
python create_video.py output_dir -o archive.mov -c prores -q high
```
Lossless or near-lossless quality for long-term storage.

### 5. Small File Size
```bash
python create_video.py output_dir -o compressed.mp4 -c libx265 -q medium -s -1:720
```
H.265 codec with 720p resolution for smallest file size.

### 6. Web/HTML5
```bash
python create_video.py output_dir -o web.webm -c libvpx-vp9 -q high
```
VP9 codec in WebM container for HTML5 video.

## Troubleshooting

### "ffmpeg not found" error
- Ensure ffmpeg is installed
- Check that ffmpeg is in your PATH
- Try running `ffmpeg -version` to verify installation

### "No images found" error
- Verify the input directory path
- Ensure images have supported extensions (.jpg, .jpeg, .png, .tif, .tiff)
- Check that images follow the stacked-NNNNN.ext naming pattern

### "Could not determine image numbering pattern" error
- Images must have sequential numbers in filenames
- Pattern should be like: stacked-00001.jpg, stacked-00002.jpg, etc.
- Ensure consistent number of digits (padding with zeros)

### Encoding too slow
- Use a faster quality preset: `-q low` or `-q medium`
- Use H.264 instead of H.265 or VP9
- Reduce output resolution with `-s` option
- Lower the frame rate with `-f 24` or `-f 30`

### Output file too large
- Use `-c libx265` for better compression
- Lower quality preset: `-q medium` or `-q low`
- Reduce resolution: `-s -1:720`
- Lower frame rate: `-f 24` or `-f 30`

### Colors look washed out
- Add `-pix_fmt yuv420p` to ensure color compatibility
- Check if source images are in correct color space
- Try different codecs (some handle colors differently)

## Advanced Usage

### Custom ffmpeg Options

If you need more control, you can modify the scripts or call ffmpeg directly:

```bash
ffmpeg -framerate 30 -i output_dir/stacked-%05d.jpg \
       -c:v libx264 -preset slow -crf 18 \
       -pix_fmt yuv420p \
       -vf "scale=-1:1080" \
       output.mp4
```

### Two-Pass Encoding (Better Quality)

For maximum quality at a target bitrate:

```bash
# First pass
ffmpeg -y -framerate 30 -i output_dir/stacked-%05d.jpg \
       -c:v libx264 -b:v 5M -pass 1 -f mp4 /dev/null

# Second pass
ffmpeg -framerate 30 -i output_dir/stacked-%05d.jpg \
       -c:v libx264 -b:v 5M -pass 2 output.mp4
```

### Adding Audio

```bash
ffmpeg -framerate 30 -i output_dir/stacked-%05d.jpg \
       -i audio.mp3 \
       -c:v libx264 -preset slow -crf 18 \
       -c:a aac -b:a 192k \
       -shortest \
       output.mp4
```

## Performance Tips

1. **SSD vs HDD**: Read/write speed matters. Use SSD for better performance.
2. **CPU Usage**: Video encoding is CPU-intensive. Close other applications.
3. **RAM**: Ensure sufficient RAM (4GB minimum, 8GB+ recommended).
4. **Batch Processing**: Process multiple directories in sequence overnight.
